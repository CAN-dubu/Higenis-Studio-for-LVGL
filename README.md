# Higenis Studio for LVGL

A lightweight Windows editor for designing LVGL v9 screens, trying them in a built-in simulator, and exporting C code or a ready-to-build Arduino sketch. (UI in Korean)

LVGL v9 화면을 도면처럼 그리는 가벼운 에디터. C++17, Win32, Direct3D 11.
캔버스는 흉내가 아니라 실제 LVGL이 그린 화면입니다.

도면 파일의 확장자는 `.hg`입니다. 예전에 만든 `.vellum` 파일도 그대로 열리고, `다른 이름으로 저장`하면 `.hg`가 됩니다.

## 내려받기

실행 파일만 필요하면 [Releases](https://github.com/CAN-dubu/Higenis-Studio-for-LVGL/releases)의 zip을 풀고 `HigenisStudio.exe`를 실행하세요. Windows 10/11 64비트용입니다.

## 빌드

Visual Studio 2022 Build Tools(C++), CMake, Ninja가 필요합니다. LVGL과 Dear ImGui는 서브모듈이라 `--recursive`로 받아야 합니다.

```powershell
git clone --recursive https://github.com/CAN-dubu/Higenis-Studio-for-LVGL.git
cd Higenis-Studio-for-LVGL
.\build.bat
```

이미 받았는데 `third_party\lvgl`이 비어 있으면 `git submodule update --init`을 실행하세요. 시험은 `tests\run.bat`입니다.

결과물은 `build\HigenisStudio.exe`와 `build\assets`(글꼴, 표준도) 두 가지입니다. 이 둘만 있으면 다른 PC에서도 실행됩니다.

## 명령줄

| 명령 | 하는 일 |
|---|---|
| `HigenisStudio.exe 도면.hg` | 도면 열기 |
| `HigenisStudio.exe 도면.hg --export 폴더` | 창 없이 C 코드 내보내기(빌드 스크립트용) |
| `HigenisStudio.exe 도면.hg --arduino 폴더` | 창 없이 아두이노 스케치 만들기 |
| `HigenisStudio.exe --script 파일 --log 파일 --size 1520x940` | 입력을 재생하고 화면을 저장(자체 점검용) |

## 용어

| 도면 용어 | 에디터에서 |
|---|---|
| 표준도 | 시작 도면. 파일 메뉴나 `Ctrl+Shift+N`으로 고른다 |
| 템플릿 | 위젯 팔레트. 끌어 놓거나, 누른 뒤 시트에 그린다 |
| 부품표 | 위젯 트리 |
| 주기 | 이벤트와 콜백 |
| 개정 이력 | 실행 취소 기록. 눌러서 그 시점으로 간다 |
| 검도 | 오류 검사(화면 밖, 이름 중복, 콜백 누락, 터치 크기, 글꼴에 없는 글자) |
| 비침 | 다른 시트를 청색 밑그림으로 겹쳐 보기 |
| 시운전 | 실제 LVGL로 돌려 눌러 보기(시뮬레이터) |
| 내보내기 | LVGL C 코드와 한글 글꼴 내보내기 |

## 보기: 매끈하게, 픽셀 그대로

화면은 척도에 맞춰 **다시 그립니다**. 자리와 크기는 LVGL이 장치 해상도에서 정한 그대로이고, 글자·기호·둥근 모서리의 윤곽만 또렷합니다.
`P`(또는 아래 막대의 `픽셀`)를 누르면 장치에 실제로 찍힐 픽셀을 키워서 보여 줍니다. 1:1에서는 둘이 같으므로 늘 장치 픽셀입니다.

## 시운전

`F5`로 시작하고 `Esc`로 도면에 돌아옵니다. 도면은 바뀌지 않습니다.

- 버튼, 스위치, 슬라이더, 아크, 드롭다운, 롤러, 스크롤이 장치에서처럼 움직입니다. 입력창은 누른 뒤 키보드로 적습니다.
- 오른쪽 **기록**에 어떤 부품에서 무슨 일이 나고 어떤 콜백이 불리는지, 값이 얼마인지 남습니다.
- **시트 이동**: 주기(이벤트)의 `이동`에서 옮겨 갈 시트를 고르면 시운전에서도 내보낸 코드에서도 그 시트로 갑니다. 콜백 없이 이동만 걸어도 됩니다.
- 콜백 안의 동작은 여러분의 C 코드이므로 시운전에서는 불린 사실만 기록합니다(예: 아크를 돌려도 온도 글자는 바뀌지 않습니다).
- 내보낼 글꼴에 없는 글자를 입력하면 장치에서처럼 빈 네모로 보이고, 그 사실을 알려 줍니다.

## 움직임

시트가 뜰 때 부품이 움직이게 합니다. 회사 소개, 부팅 화면 같은 짧은 모션 그래픽을 도면 안에서 만들 수 있습니다.

- 부품 속성의 **05 움직임**에서 `+ 움직임 추가`. 한 부품에 여러 개를 걸어 순서대로 움직이게 합니다(나타났다가 머물다 사라지기 등).
- 종류: 들어오기(나타나기·밀려오기·커지기·펼치기·글자 치기), 나가기(사라지기·밀려나기·작아지기), 되풀이(두근두근·깜빡이기·돌기).
- 시작(ms)은 시트가 뜬 때부터 셉니다. 느낌은 일정하게, 부드럽게 멈춤, 부드럽게 출발·멈춤, 살짝 넘쳤다 제자리, 통통 튀기 가운데서 고릅니다.
- **저절로 넘어가기**: 시트 속성에서 다음 시트와 시간을 정하면 그때 다음 시트로 갑니다.
- **움직임 표**: 시트 속성에 시트의 움직임이 시간 축으로 늘어섭니다. 눈금 줄을 끌면 도면이 그 순간의 모습으로 그려지고, 줄을 누르면 그 부품을 고릅니다.
- 도면은 평소에 움직임 없이 놓인 모습입니다. 시운전(F5)에서 움직이고, `Ctrl+R`로 처음부터 다시 봅니다.
- 내보낸 코드에서는 `higenis_fx.c`의 `higenis_motion()`, `higenis_after()`가 같은 움직임을 냅니다(LVGL 9.1 이상).

## 그림

파일(PNG·JPG·BMP·GIF)을 창에 **끌어다 놓으면** 그 자리에 들어갑니다. 이미지 부품 위에 놓으면 그 그림을 바꿉니다. 부품을 두 번 눌러 고를 수도 있습니다.

- 그림은 `.hg` 도면 안에 함께 저장됩니다. 원본 파일이 없어도 됩니다(긴 쪽 2048px까지).
- **맞추기**: 채움(잘라서 꽉 차게), 맞춤(전체가 보이게), 늘림, 원본.
- **액자**: 스타일의 테두리·모서리 반경·배경·그림자가 그림에 그대로 적용됩니다. 반경을 크게 하면 원형 사진이 됩니다.
- **보관**: 플래시는 C 배열로, SD 카드는 LVGL `.bin` 파일로 나갑니다. 둘 다 부품 크기에 맞춰 미리 줄이고 RGB565로 바꿔 두므로 장치가 실행 중에 확대·축소하지 않습니다.
- SD에 **이미 있는** `.bin`은 그림을 비워 두고 보관을 `SD 카드`로 한 뒤 경로만 적으면 됩니다. JPG·PNG 파일을 카드에서 바로 읽는 방식은 아닙니다.

- **손보기**: 보이는 자리(채움·원본), 흐리게, 밝기, 채도, 그늘(아래·위·전체), 도트 또렷하게, 배경 지우기(단색·체크무늬). 장치에 넣기 전에 미리 처리하므로 실행 중에는 부담이 없습니다.
- **투명하게·물들이기**: 스타일의 `그림`에서 불투명도와 색을 정합니다. 상태(눌림 등)마다 다르게 할 수 있습니다.

## 글자

- **글꼴**: 스타일의 `글꼴`에서 함께 든 다섯 가지, PC에 설치된 글꼴, 글꼴 파일 가운데 고릅니다. 컨테이너에 정하면 안의 글자가 물려받습니다.
  도면에는 **쓴 글자의 윤곽만** 담기므로 그 글꼴이 없는 PC에서도 그대로 보입니다(새 글자는 기본 글꼴로 나오고 검도가 알려 줍니다). 내보낼 때는 쓴 글자와 숫자·부호만 담습니다.
  PC 글꼴은 **배포하기 전에 사용 조건을 확인하세요.** 내장을 제한한 글꼴이면 알려 줍니다.
- **투명도**: 글자, 배경, 그림, 전체를 %로 조절합니다.
- **글자 꾸밈**(라벨): 그림자, 외곽선, 번짐. `higenis_fx.c`로 함께 나가며 LVGL 9.1 이상의 공개 함수만 씁니다. 번짐은 글자를 49번 그려 느린 장치에서는 무겁습니다.
- **밑판**: 어둡게, 밝게, 형광펜을 한 번에. 글자색도 읽히는 쪽으로 맞춥니다.
- 정렬, 글자 사이, 줄 사이, 밑줄·취소선. 크기를 정한 라벨은 긴 글을 줄바꿈·점줄임·흐르기·자르기로 처리합니다(흐르기는 시운전에서 움직입니다).
- **검도**: 라벨 아래 그림과 색이 비슷해 글자가 안 읽히면 몇 %가 안 보이는지 알려 줍니다.

## 아두이노

내보내기 창(`Ctrl+E`)에서 `아두이노`를 고르면 바로 열어 업로드할 수 있는 스케치 폴더가 나옵니다.

- 화면 드라이버(TFT_eSPI, Adafruit ILI9341·ST7789, JD9165 MIPI-DSI, 직접 작성), 핀, 방향, 터치(XPT2046, TFT_eSPI, GT911), **그리기 버퍼** 크기와 장수, PSRAM, 화면 주기, SD 카드(SPI, SDMMC)를 창에서 정합니다.
- `보드` 목록에서 알려진 보드를 고르면 한 번에 채웁니다: CYD(ESP32-2432S028), **JC1060P470**(ESP32-P4, 7인치 1024 × 600, GT911, TF 카드).
- JC1060P470은 추가 라이브러리 없이 ESP32 보드 패키지 3.1 이상만으로 컴파일됩니다. LVGL은 내부 RAM에 그리고 DMA2D가 화면 버퍼로 옮기며, 두 코어가 나눠 그립니다. 터치는 다섯 손가락까지 읽습니다(`higenis_touch_point()`). 밝기는 `higenis_backlight()`.
- **LVGL 9.1 이상**이 필요합니다. 8.x 라이브러리로는 컴파일되지 않습니다.
- ESP32는 `build_opt.h`가 LVGL 설정을 대신하므로 `lv_conf.h`를 만질 필요가 없습니다. 다른 보드는 함께 나오는 `lv_conf.h`를 libraries 폴더에 복사합니다.
- 콜백은 `.ino`에 직접 만들면 그것이 쓰이고, 만들지 않으면 빈 함수가 쓰입니다. 다시 내보내도 `.ino`는 덮어쓰지 않습니다.
- ESP32, ESP32-S3, ESP32-C3, ESP32-P4(코어 3.3.12)와 Raspberry Pi Pico(rp2040 코어)에서 실제로 컴파일해 확인했습니다. JC1060P470 실기 동작은 아직 확인하지 않았습니다.

아홉 장이 들어 있습니다. 새 도면으로 시작하거나, 해상도가 같으면 지금 도면에 시트로 더합니다.

**내 표준도 더하기**: `assets\standards` 폴더에 `.hg` 파일을 넣고 다시 켜면 됩니다. 파일 이름 순서로 놓입니다.
설명과 출처는 파일 첫머리에 `about`과 `credit` 줄로 적습니다(이름과 내용 사이는 탭).

## 기호, 게이지, 원형 화면

- **기호**: 라벨·버튼·체크박스의 글자 칸 옆 `기호`에서 LVGL 내장 기호 59개를 고릅니다. 내보내면 `LV_SYMBOL_WIFI` 같은 매크로가 됩니다.
- **게이지**: 아크의 `게이지`를 켜면 손잡이가 사라지고 만질 수 없는 표시용이 됩니다.
- **원형 화면**: 해상도가 정사각형일 때 켤 수 있습니다. 화면 밖으로 잘리는 귀퉁이를 덮어 보여 주고, 검도가 그 자리의 부품을 알려 줍니다.
- 글자 크기는 10~28, 36, 48px입니다.

## 한글

라벨·버튼 같은 글자에 한글을 그대로 쓰면 됩니다. 내보낼 때 **화면에 쓴 글자만** 뽑아 `ui_font.c`를 함께 만듭니다.

- 원래 글꼴(Montserrat)은 그대로 두고, 없는 글자만 이어 붙입니다(LVGL `fallback`). 영문과 숫자 배치는 달라지지 않습니다.
- 글자는 IBM Plex Sans KR에서 뽑습니다. OFL 라이선스 전문(`ui_font_OFL.txt`)이 함께 나가니 배포할 때 포함하세요.
- 실행 중에 바뀌는 글자(예: 서버에서 받은 이름)는 도면에 없으므로 글꼴에도 없습니다. 그런 글자는 어딘가에 미리 적어 두어야 담깁니다.
- 이모지와 일부 한자는 담을 수 없어 검도가 오류로 알려 줍니다.

## 시험

```powershell
.\tests\run.bat
```

창을 띄우지 않고 마우스와 키보드 입력을 재생해, 결과가 기대와 같은지 하나씩 따집니다.

## 구조

| 파일 | 역할 |
|---|---|
| `src/model.cpp` | 위젯 트리, 개정 이력, 검도, 저장과 불러오기 |
| `src/lvhost.cpp` | 모델을 실제 LVGL 객체로 만들어 렌더링, 시운전 |
| `src/fontface.cpp` | 글꼴 고르기, 도면에 담는 윤곽 |
| `src/higenis_fx.c` | 글자 꾸밈(미리보기와 내보낸 코드가 함께 쓴다) |
| `src/fonthint.cpp` | 글자 획을 픽셀에 맞추기(편집기와 장치 글꼴) |
| `src/image.cpp` | 그림 읽기, 크기 맞추기, LVGL 형식으로 바꾸기 |
| `src/arduino.cpp` | 아두이노 스케치 생성 |
| `src/smooth.cpp` | LVGL의 그리기 명령을 화면 배율로 다시 그리기 |
| `src/codegen.cpp` | LVGL v9 C 코드 생성 |
| `src/fontgen.cpp` | 쓴 글자만 담은 글꼴 생성(미리보기와 내보내기가 함께 쓴다) |
| `src/ui_kit.cpp` | 팔레트, 글꼴, 치수선·개정 구름·도장, 컨트롤 |
| `src/ui_canvas.cpp` | 시트, 자, 선택, 스냅, 거리 재기, 표제란 |
| `src/ui_panels.cpp` | 상단, 템플릿, 부품표, 속성, 내보내기·검도 창 |
| `src/ui_sim.cpp` | 시운전 화면 |
| `src/main.cpp` | 창, Direct3D 11, 파일 대화상자 |

Chivo Mono는 가변 글꼴에서 굵기 400만, Montserrat는 LVGL 기본 글꼴에 든 글자만 뽑은 것입니다.

배포할 때는 `assets` 폴더를 통째로 함께 넣으세요. 라이선스 고지는 `assets/THIRD_PARTY_NOTICES.txt`, 글꼴 라이선스 원문은 `assets/fonts`에 있고,
프로그램 안에서는 왼쪽 위 이름표(또는 파일 → 프로그램 정보…)로 볼 수 있습니다.
LVGL은 해당 권리자의 상표이며, 이 제품은 LVGL 프로젝트와 관계가 없습니다.

## 알려진 한계

- 고른 글꼴에는 자간 조정(커닝)이 없습니다. 이모지 같은 색 글꼴은 쓸 수 없습니다.
- 글자 꾸밈은 라벨에만 됩니다.
- 표준도의 날씨 그림은 둥근 상자로 그린 것입니다. 그림 파일을 쓰려면 이미지 부품으로 바꾸세요.
- 어두운 테마의 표준도를 밝은 도면에 시트로 더하면, 테마 색을 쓰는 부분(꺼진 스위치 등)이 달라집니다.
- 원형 화면은 미리보기와 검도만 다릅니다. 내보낸 코드는 정사각형 화면과 같습니다.
- 그림의 움직임(GIF 재생)은 첫 장만 씁니다.
- 아두이노의 화면 드라이버는 위 네 가지입니다. RGB 패널 등 다른 화면은 `직접 작성`으로 이어야 합니다.
- 여러 손가락은 직접 읽을 수 있지만, LVGL의 핀치·회전 제스처에는 아직 잇지 않았습니다.
- 매끈하게 보기는 화면용입니다. 실제 장치의 글자는 `픽셀` 보기와 같습니다.
- 시운전의 빠르기는 PC 기준입니다. 장치의 CPU와 화면 전송 속도는 흉내 내지 않습니다.
- 한 번에 부품 하나만 선택합니다.
- Windows 전용입니다.
